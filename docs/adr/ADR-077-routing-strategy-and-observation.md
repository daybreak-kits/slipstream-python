# ADR-077 路由策略：默认同层负载均衡、可选调优、观察期

- 状态：accepted（2026-11-16 用户裁定）
- 关联：ADR-076（准入控制同期落地）、GLOSSARY §10（路由策略词条）、ssot §4 路由

## 背景

用户裁定：**不做用户无感的自动调优作为默认**。跨层顺序由优先级绝对控制（现状不变）；同层成员的选择从「永远均匀随机」升级为可选策略，且策略只在成员有足够窗口数据时生效。

## 决策

1. **默认策略 = 同层负载均衡**（均匀随机），即现状行为，保持为默认与回退。
2. **可选策略（同层内排序）**：
   - `stable` 稳定优先：窗口内成功率降序（成功尝试 ÷ 总尝试）。
   - `cost` 成本优先：**每百万 token 有效均价**升序 = 窗口内 Σ实际计费费用 ÷ Σ(prompt_tokens + completion_tokens) × 1M。prompt_tokens 已含缓存命中部分，实际费用里缓存读取/写入按各自单价计（缓存命中单独收费，命中越多有效均价越低——奖励缓存友好行为）；按 token 归一，大会话/小会话公平；**未配置价格的成员按 0（免费）参与**。（2026-11-16 用户复议：单次请求均价比会因会话大小失真，否决）
   - `latency` 延迟优先：窗口内 TTFA P50 升序（不用均值，防长尾污染）。
3. **时间窗口**：滑动窗口，按尝试的事件时间回看。选项 15/30/60 分钟或自定义，**最小 15 分钟、上限 24 小时（1440 分钟）**，默认 30。窗口太小拿不到样本（用户裁定）。
4. **观察期（用户裁定，30 次）**：窗口内成功尝试 **< 30 次**的成员（新加入的、或冷却解除时历史数据已滑出窗口的）按**负载均衡均等参与**——在调优排序中占据均匀随机槽位，跑满完整窗口攒足样本后才并入策略排序。窗口内任何成员都没有足量样本时，整层回退均匀随机。
5. **优先级不变**：`priority` 仍然控制跨层绝对尝试顺序；策略只作用于同层内部。
6. **挂载位置**：全局默认（策略 uniform + 窗口 30 分钟）存 `app_settings`；**组合级可覆盖**（策略与窗口两字段），渠道直连与隐式分组用全局默认。
7. **准入控制同期落地**（ADR-076 决策 5）：节点级最大在飞数（流式+非流式，仅 `/v1/*`），过载 429 + `Retry-After`；默认 256 生效，`0` = 关闭；env 与设置页可调。

## 明确不做

- 不做跨层自动调优（优先级语义不动）。
- 不做逐请求重排序以外的预测/学习机制；观察期机制即防「新成员永远排最后」。
- 窗口统计只读既有 `request_logs`/attempts 数据，不新增埋点写入路径。
